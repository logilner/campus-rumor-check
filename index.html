      What this does

      1. Extracts the core claim from what you paste, stripping "I heard…"-style framing.
      2. Categorizes it — safety, personnel, enforcement, operations, or general.
      3. Matches it against a cached feed of recent items from verified sources, and (if enabled) has Claude run a live web search limited to those same sources.
      4. Returns a status: confirmed by an official source / being reported by local news / no match found — with links.

        Limits — read this

        • "No match found" is not an all-clear. Official alerts can lag a real event, and this tool only sees what has been published to the sources above. In a possible emergency, act on official channels and 911, not on this.
        • The cached source feed is only as fresh as the last run of fetch_sources.py (shown on each result).
        • Claim extraction is heuristic. Check the "we read your rumor as" line — if it's off, rephrase and re-run.
        • Crime-log entries are scraped best-effort and unreviewed; treat them as leads, not confirmed facts.
        • This is a student-built tool, not affiliated with the University of Nebraska–Lincoln or any news outlet.
